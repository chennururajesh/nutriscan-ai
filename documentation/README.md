# NutriScan AI - Academic Documentation Directory

This directory stores research manuscripts, system architecture specifications, testing reports, and the final project thesis PDF.

## Subdirectories:
- `research_papers/`: Literature review and references on food adulteration (FSSAI, AOAC) and TinyML edge computing.
- `system_architecture/`: Detailed Dew computing framework specification, network state diagrams, and pipeline models.
  - [DEW_COMPUTING_SPECIFICATION.md](system_architecture/DEW_COMPUTING_SPECIFICATION.md)
- `testing_reports/`: Empirical evaluation metrics, latency benchmarks, and CSV exports.
  - `performance_benchmarks.csv`
- `final_report/`: Dedicated target directory for the finalized academic major project thesis PDF.
