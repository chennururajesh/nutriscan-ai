# NutriScan AI - Release Artifacts Directory

This directory is designated for final release binaries and milestone archives.

## Directory Structure:
- `apks/`: Target destination for signed, compiled Android application packages (`.apk` and `.aab`).
- `source_archive/`: Target destination for zipped source code milestones (`.zip`).

> **Academic Integrity Notice**:
> In accordance with project requirements, no placeholder, simulated, or dummy APK files are created here. Compiled APKs will be output directly upon running official Gradle release build tasks with an active Android SDK.
